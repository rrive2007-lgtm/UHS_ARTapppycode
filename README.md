# Union High School Student Art Wall — Python demo

## Publish free with Streamlit Community Cloud
1. Create a GitHub account and a new repository.
2. Upload `app.py`, `requirements.txt`, and `union-logo.png` to the repository root.
3. Visit https://share.streamlit.io/ and connect your GitHub account.
4. Choose your repository, branch `main`, and main file `app.py`, then deploy.
5. Streamlit will provide a shareable `*.streamlit.app` link.

## Demo features
- School art wall design and supplied Spartan logo
- Responsive layout with gallery, submission, and community-rules tabs
- Image upload, title, artist alias / anonymous default, and permission checkbox
- Preview submissions in the current app session

## Important
This is a prototype. It does not permanently save uploads or publish a shared public gallery. Session previews may reset. Before real school use, add persistent storage, moderation, access controls as needed, and school approval. Avoid collecting unnecessary student personal information.
